# Hey, I'm Brian

I've spent about 20 years as a creator, mostly around business, culture, and the attention economy. These days I also build the tools I actually want to use at home — with AI agents, in the open.

## Family Hub

**[Family Hub](https://github.com/thebrianlee/family-hub)** is a dashboard for a screen in your kitchen. It shows the day at a glance: calendar, routines, meals, lists, and a few other household tools. It runs on a computer in your house, such as a Raspberry Pi. There is no cloud account and no subscription.

If you want to try it, or help make it easier for non-technical people to set up, start at the repo. Questions and ideas are welcome in GitHub Discussions; bugs go in Issues.
